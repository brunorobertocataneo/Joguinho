# ♡ Nossos Universos

Uma aventura romântica em formato de site interativo, pensada para celular e computador.

## O que já funciona
- Tela inicial com visual chibi/pastel.
- Três mundos: One Piece, Fullmetal Alchemist e Naruto.
- Minijogo de perguntas para desbloquear cada mundo.
- Progresso salvo no navegador (localStorage).
- Baú com Vale Fini e convite para Overcooked.
- Declaração final desbloqueada depois de completar as três fases.
- Animações, corações e acessibilidade básica.

## Executar
Basta abrir `index.html` em um navegador. Sem npm, build ou instalação.

## Imagens do casal
Para mostrar as artes originais, crie a pasta `assets` e coloque estes arquivos nela:

| Arquivo | Uso |
|---|---|
| `casal.webp` | Ilustração do casal na abertura |
| `onepiece.webp` | Arte inspirada em One Piece |
| `fullmetal.webp` | Arte inspirada em Fullmetal Alchemist |
| `naruto.webp` | Arte inspirada em Naruto |
| `fini.webp` | Vale Fini |
| `overcooked.webp` | Convite Overcooked |

Se faltar alguma arte, o site exibe um visual alternativo para não quebrar.

O pacote ZIP entregue na conversa contém todos os arquivos e imagens prontos, bastando enviar a pasta `assets` ao repositório.

## Publicação no GitHub Pages
No repositório, abra **Settings → Pages → Build and deployment**; em **Source**, selecione **Deploy from a branch**, escolha **main** e **/(root)** e salve. Pode ser necessário mudar a visibilidade do repositório para uma configuração compatível com o seu plano de Pages.

## Personalização
As frases e os desafios estão no array `worlds` dentro de `index.html`. Tudo foi feito em HTML, CSS e JavaScript puro.
