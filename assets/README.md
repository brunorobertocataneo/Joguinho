# Imagens do site

Os seis arquivos WebP esperados pelo site são:

- `casal.webp` — tela inicial
- `onepiece.webp` — mundo One Piece
- `fullmetal.webp` — mundo Fullmetal Alchemist
- `naruto.webp` — mundo Naruto
- `overcooked.webp` — convite Overcooked
- `fini.webp` — Vale Fini

O pacote `Joguinho_assets_prontas.zip` entregue na conversa contém exatamente esta pasta `assets` com as imagens otimizadas. Extraia e arraste **todos os seis arquivos** para esta pasta no GitHub, clicando em **Add file → Upload files**.
