# Nossos Universos — A Grande Aventura 2D

Jogo de navegador original inspirado em mapas de seleção de fases de jogos clássicos, com três aventuras temáticas: **One Piece**, **Fullmetal Alchemist** e **Naruto**. Arte e elementos de cenário desenhados em Canvas, sem copiar sprites de jogos comerciais.

## Abrir

Abra **index.html** com Chrome ou Edge. Não é necessário instalar pacotes nem servidor.

## Como jogar

1. Clique em Começar a viagem.
2. Escolha a primeira ilha no mapa.
3. Use **A / D** ou as **setas horizontais** para andar.
4. Pule com **Espaço / W / ↑**.
5. Colete as três estrelas e alcance o portal.
6. A ilha seguinte é desbloqueada automaticamente; o progresso fica salvo no navegador.
7. Use o botão Voltar ao mapa para explorar e rejogar.

## Recursos

- Mapa animado com três ilhas, rotas de viagem, oceano, navios, nuvens, sombras, iluminação e efeitos.
- Três fases jogáveis de plataforma com câmera, parallax, obstáculos, inimigos e estrelas.
- Cenários com identidade própria por universo.
- Progresso armazenado em localStorage.
- Controles por toque no celular.
- Efeitos sonoros gerados via WebAudio.
